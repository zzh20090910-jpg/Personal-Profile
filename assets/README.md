## Cartoon portrait

hower-cartoon.webp is an AI-generated cartoon portrait based on a reference supplied by the site owner, published with their permission. The original reference photograph is not included. The portrait's eye interiors are intentionally blank in the raster asset; index.html adds clipped SVG pupils so the portrait has centered eyes even without JavaScript. avatar-tracking.js moves the pupils with the pointer and respects reduced-motion preferences.
